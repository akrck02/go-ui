Components

Every Go UI control, one by one: what it is for, concrete cases with their code, how it behaves with the mouse, the keyboard, a finger and a screen reader, and its options. Each case is a real program’s code; the pictures are captures of it.

All the cases assume the usual frame: context is the *ui.Context your build function gets (window.Run) or that you call Begin and End on. State such as tab or foghorn is a variable of your program that lives between frames.

Rules every control follows

  • A control is a call. It is drawn in the frame it is called in, and gone in the frame it is not. Show it with an if; repeat it with a for.
  • It answers what happened in this frame. Buttons return true on the frame they are clicked; controls that edit a value take a pointer to it and return true on the frame they change it.
  • It is told apart by its label and its scopes (its id). In a loop, open a scope per item with context.Push(name) … context.Pop(). Text after ## is part of the id but not shown.
  • Colours and sizes come from context.Theme. Change a token and every control follows.
  • The pointer works from the last frame’s layout, so a control reacts where it was drawn.
